# カカオ・ショコラのC案

2026-10-03採用。三ツ葉 葵を絵柄の基準とし、白いコックコート、赤いスカーフ、茶色いエプロン、チョコレートを持つ姿を維持。動きのある髪、細めの琥珀色の目、自信のある微笑みを採用する。

- 顔アイコン・人物画像：`public/assets/characters/cacao-c.png`（1024×1536）。採用されたC案の原画像をコピーし、顔部分は共通のPortraitコンポーネントとCSSで表示する。
- 物語・デート・プレゼント反応：`public/assets/characters/cacao-c-story-cutout.png`（1024×1536、透過PNG）。
- 従来の画像は残し、`src/data/characters.ts`の参照先を変更した。店内の小さなスタッフ用スプライトは別素材を使用する。

## 生成方法とプロンプト

組み込みのimagegenを使用。参照画像は葵の`aki.png`と、従来の`cacao-story-cutout.png`。

C案の指定：葵と同じ茶色の輪郭線、丸みのある若い成人男性の顔、淡い水彩と紙の質感、簡略化した陰影と頭身。カカオの濃い茶色の髪、琥珀色の瞳、衣服と小物を維持し、軽いレイヤーと外へ跳ねる毛先、柔らかい前髪、少し吊り上がった細めの目、片方の眉を上げた挑発的な閉じ口の笑みを指定。そばかす、新しい装飾や衣服、文字は追加しない。全身を中央に置き、生成時の背景は淡い紙色。

透過用の指定：採用されたC案を参照し、紙色の背景のみ除去して透過する。髪、目、表情、ポーズ、頭身、衣服、小物、茶色の線、水彩の質感を保持。白いコックコートは不透明にし、全身が入る1024×1536のPNGとする。
